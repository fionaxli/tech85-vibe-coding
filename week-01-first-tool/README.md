# Week 1: What vibe coding is, and your first AI-built tool

**Session:** Tue Jan 19, 2027, 7:00–8:30 pm PT

## Goals

Set up your tools, describe a small task in plain language, and get working code from an AI coding assistant.

## In class

- Short lecture
- Live demo
- Lab: Install the tools, then build a one-file script from a plain-language request.

## Lab steps

1. Install Python 3.10+ and VS Code (see the main [README](../README.md)).
2. Download this repository and open the `starter` folder in VS Code.
3. In a terminal, run `python word_counter.py sample.txt` and check the output.
4. Ask your AI assistant to change one thing about the tool, for example: "Also ignore the words 'you' and 'what', and show the top 10 words."
5. Run it again on `sample.txt`, then on a text file of your own.
6. Read the new code with the assistant: ask it to explain each change in one sentence.

## Before next week

Write down one task you'd like to automate or a small tool you wish existed. You'll turn it into a spec in Week 2.
