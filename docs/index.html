About the course

Most coding courses teach you to write code. This course teaches you to direct an AI that writes code for you — then read, test, and own what it builds.

You will leave with three real, deployed projects and a mental model that transfers to every tool that comes next. The skill you are developing is not Python syntax. It is context engineering: knowing how to give an AI coding agent the right information at the right time, so it builds exactly what you have in mind.

This course uses Claude Code exclusively — one tool, learned deeply, from Week 1 through Demo Day.

What you will be able to do

  1. 1 Launch Claude Code and direct it to build a working web application from a plain-language description
  2. 2 Write a BRIEF.md specification that gives an AI coding agent everything it needs to get started
  3. 3 Read AI-generated code confidently — enough to catch errors, ask good follow-up questions, and make informed decisions
  4. 4 Connect your app to a database (SQLite) and an external API, without managing a server
  5. 5 Use Git to checkpoint your work before risky changes, and roll back when something breaks
  6. 6 Describe bugs precisely enough that Claude Code can diagnose and fix them
  7. 7 Deploy a working app to a public URL and walk someone through it in three minutes
