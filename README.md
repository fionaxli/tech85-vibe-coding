## Getting the materials

- **No account needed:** click the green **Code** button, then **Download ZIP**.
- **With Git:** `git clone <repository URL>` (covered in Week 5).

## What you need

- A laptop (macOS, Windows, or Linux) you can install software on
- [Python 3.10+](https://www.python.org/downloads/)
- [VS Code](https://code.visualstudio.com/) or another code editor
- Access to at least one AI coding assistant. Setup is covered in Week 1.

This course relies on third-party AI tools that are not managed or supported by Stanford. Some have free tiers or trials; paid plans typically cost $25–$100 per month if you reach usage limits. See the syllabus on Canvas for details.

## Using this repository

- These materials are for learning. Read and understand AI-generated code before you run it.
- Do not commit passwords, API keys, or personal data. Keep keys in a local `.env` file, which this repository ignores.
- Found a mistake? Post it in the Canvas discussion board.
